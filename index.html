# about

I'm a backend software engineer who likes solving the unglamorous problems underneath an application — how data is structured, how it moves, and how the whole thing stays reliable once real usage hits it.

That focus shows up clearest in my POS system project, where I designed the database schema, built the backend in Python, and worked through the kind of tradeoffs that come with any system meant to handle real transactions — data integrity, structure that scales, and how the pieces connect end to end. I've also worked with AWS to understand how backend systems actually get deployed and run in production, not just built locally.
